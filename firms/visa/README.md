# Visa — public reconstruction

## Public

- **VisaNet** — centralized modular payments network; authorization, clearing/settlement (BASE II named in public overviews), STIP stand-in.
- **Visa as a Service** — 2025 ARS: foundation / services / solutions / access layers; APIs + MCP server for Visa Intelligent Commerce.
- **Ops** — NOC + Risk Operations Center; seven independent data centers; 99.9999% uptime claimed; 65k+ msg/s peak (Visa Perspectives).
- **Open VisaNet** — next-gen / cloud-native direction cited in secondary coverage; treat as direction, not a finished map.

## Unknown

- CRM / ITSM.
- Exact issuer/acquirer host stacks (those are clients, not Visa).
