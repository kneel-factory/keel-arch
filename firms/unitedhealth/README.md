# UnitedHealth Group — public reconstruction

10-K shape only. Two businesses: **UnitedHealthcare** (benefits) and **Optum** (Health / Insight / Rx). Do not invent claims-adjudication or EMR names.

## Public

- **UnitedHealthcare** — Employer & Individual, Medicare & Retirement, Community & State (reportable).
- **Optum Health** — care delivery / value-based care (10-K).
- **Optum Insight** — data, analytics, tech, managed services (10-K).
- **Optum Rx** — PBM / pharmacy care (10-K).
- **Change Healthcare / Optum Intelligent Health Care Network** — clearinghouse + Medical Network APIs (developer.optum.com): eligibility, claims, attachments; X12 translated to JSON. FHIR/HL7 cited as interoperability standards on careers + API docs.
- **Member digital** — uhc.com / app exist as channels. Stack **unnamed**.
